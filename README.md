# optpoet — 光学的韻律を持つ画像詩生成システム

モノクロ写真を、日本語の文章だけで構成されたアスキーアートへ変換するアート作品プロジェクト。

写真の明暗・輪郭・光の分布を、文字の視覚密度・書体・文字種・語彙・文法構造へ変換する。
詩が音数や韻によって時間的リズムを形成するように、本作品では写真の光学的構造が文章へ視覚的なリズム（**光学的韻律**）を与える。

## 三つの同時成立

1. **見ると写真** — 遠景では元写真の構図が認識できる
2. **読むと文章** — 近景では日本語の文章として読める
3. **密度変化そのものが韻律** — ひらがなと漢字の切り替わり、書体の変化がリズムになる

画像再現性だけを重視すると文章が崩れ、文章だけを重視すると画像が崩れる。この緊張関係を作品の本質として扱う。

## 仕組みの概要

```
入力写真
  → 画像前処理（グレースケール化・コントラスト調整）
  → 文字グリッドへ縮小 → 密度マップ生成
  → 写真内容の解析（キャプション・感情・象徴）
  → 密度制約付き文章生成（LLM草稿 → 言い換え最適化）
  → 文字配置・レンダリング（漢字=ゴシック体 / ひらがな=明朝体）
  → 視覚誤差評価・文章品質評価 → 再生成・最適化
  → 完成作品（MVP: PNG / TXT / project JSON、MVP後: SVG / PDF）
```

- 白い領域: 画数が少ない文字、余白の多いひらがな
- 中間領域: 一般的なひらがな、カタカナ、画数の少ない漢字
- 黒い領域: 画数が多い漢字、複雑な字形

密度は画数ではなく、実際に使用するフォントでラスタライズした黒画素率で測定する（文字密度辞書）。

## 生成モード

| モード | 内容 |
|--------|------|
| 記述モード | 写真の内容を比較的自然に記述 |
| 散文詩モード | 感情・象徴を含む詩的な文章 |
| 光学詩モード | 明暗と文字密度を最優先した生成 |
| カットアップモード | 複数の文章断片を写真の明暗に従って切断・再配置 |
| 視覚優先モード | 文章の自然さを犠牲にして写真再現を優先 |

文章の破綻は最適化の失敗ではなく、**調整可能な表現パラメータ**（文法秩序 1.0〜0.0）として扱う。

## 技術構成（予定）

- コア処理: Python（Pillow / OpenCV / NumPy / scikit-image / SudachiPy）
- 文章生成: LLM API + アルゴリズムによる文字密度最適化の二段階構成
- 探索: ビームサーチまたは局所探索
- UI: 初期版は Gradio または Streamlit
- データ保存: JSON + SQLite
