# Phase 1: 文字による画像再現

**状態**: 完了（2026-08-10 完了ゲート P1-G01〜P1-G05 通過）  
**目標**: AI を使わず、任意の日本語文章を画像密度へ合わせて描画・保存できる。  
**依存**: [Phase 0](phase-0.md)  
**次**: [Phase 2](phase-2.md)

## 成果物

- 画像前処理、密度マップ、文字密度辞書
- 既存テキストの文字数調整と密度最適化
- PNG / TXT / project JSON、比較表示、誤差評価

## P1-A プロジェクト基盤

- [x] **P1-001** Python パッケージ、設定、テスト、静的解析の最小構成を作る。
- [x] **P1-002** project manifest の読込・検証・保存を実装する。
- [x] **P1-003** 内容ハッシュによる成果物 ID とキャッシュ領域を実装する。
- [x] **P1-004** 原子的保存と直前の有効版を保持する処理を実装する。
- [x] **P1-005** 工程別の進捗・取消・構造化エラーを共通化する。

## P1-B 画像入力と密度マップ

- [x] **P1-010** JPEG / PNG / TIFF / WebP の正常・破損・上限超過を判定する。
- [x] **P1-011** EXIF Orientation、ICC、透過を正規化する。
- [x] **P1-012** トリミング、回転、明るさ、コントラスト、反転、ガンマを非破壊設定にする。
- [x] **P1-013** グリッド寸法と実測セル比から縮小領域を計算する。
- [x] **P1-014** 平均明度、局所コントラスト、エッジ重みの密度マップを生成する。
- [x] **P1-015** 元画像、前処理後、密度マップ、エッジ結果のプレビューを生成する。
- [x] **P1-016** 50MP / 100MB 境界とメモリ上限をテストする。

## P1-C フォントプロファイル

- [x] **P1-020** フォントファイルを読み込み、ハッシュとメタデータを保存する。
- [x] **P1-021** 許可文字集合を NFC で確定し、文字一覧を版管理する。
- [x] **P1-022** 各文字を基準セルへ描画し、黒画素率を測定する。
- [x] **P1-023** フォント・ウェイト・サイズ・描画設定を辞書キーへ含める。
- [x] **P1-024** 欠落グリフと暗黙代替フォントを検出する。
- [x] **P1-025** 密度クラス 5〜10 段階を設定可能にする。
- [x] **P1-026** 同じ条件で辞書を再生成した結果が一致することをテストする。

## P1-D テキスト配置と最適化

- [x] **P1-030** 入力文の NFC 正規化と許可文字検査を実装する。
- [x] **P1-031** 句読点・空白を含むセル数計算と改行規則を実装する。
- [x] **P1-032** 不足・超過時の調整候補を示し、暗黙削除を禁止する。
- [x] **P1-033** 各位置の目標密度と文字密度の誤差を計算する。
- [x] **P1-034** 意味を考慮しない基準配置を実装し、比較用ベースラインにする。
- [x] **P1-035** 表記候補または許可置換による局所探索を実装する。
- [x] **P1-036** 改善停止、反復上限、取消を実装する。
- [x] **P1-037** 候補、採否、評価値の最適化トレースを保存する。

## P1-E 描画・比較・出力

- [x] **P1-040** 密度辞書と同じ描画エンジンでグリッドを描画する。
- [x] **P1-041** 行間、字間、文字色、背景色、二値化、反転を反映する。
- [x] **P1-042** PNG、UTF-8 TXT、project JSON を書き出す。
- [x] **P1-043** TXT のセル列と PNG の描画列が一致することを検証する。
- [x] **P1-044** 差分、ヒートマップ、密度波形を表示する。
- [x] **P1-045** MAE、SSIM、エッジ一致率を記録する。
- [x] **P1-046** 保存・再読込後に同じ TXT / PNG を再生する。

## 完了ゲート

実行記録は [phase-1-gate.md](../environment/phase-1-gate.md)（2026-08-10 実行）。

- [x] **P1-G01** 固定 12 画像で AC-01 と AC-02 を全件満たす。→ 24 ケース全件で表示文字数 = セル数、欠落グリフ・暗黙代替 0 件。
- [x] **P1-G02** AC-03 の密度 MAE を両尺度で測定し、改善率・除外枚数・探索記録を保存する。→ 改善率中央値 密度領域（判定値）1.21% / 画素領域（補助）0.08%、除外 0 枚、24 ケースすべてに探索記録。20% の合否判定は [P2-G01](phase-2.md)（[OI-004](../decisions/open-issues.md)）。
- [x] **P1-G03** 破損画像、上限超過、欠落グリフ、容量不足で安全停止する。→ 6 事象すべてで構造化エラー停止、容量不足は直前の有効版を保持。
- [x] **P1-G04** AI なしで保存・再読込・再生が完了する。→ `ai_calls` 0 件で TXT / PNG がバイト一致。
- [x] **P1-G05** 2,000 / 5,000 セルの工程別性能記録がある。→ 合計中央値 2.7 秒 / 4.3 秒（NFR-04 の上限を大きく下回る）。
