# Phase 5: 展示システム

**状態**: 未着手  
**目標**: 制作ツールを大判出力、展示、映像・音響を含む安定した作品システムへ拡張する。  
**依存**: [Phase 4](phase-4.md) と展示要件レビュー  
**次**: 継続運用

## 成果物

- 展示用 UI と高解像度出力
- カメラ・動画・リアルタイム生成パイプライン
- プロジェクター・LED・音響連携
- 設営、監視、復旧、撤収手順

## P5-A 展示要件

- [ ] **P5-001** 会場、鑑賞距離、画面・紙面寸法、照度を記録する。
- [ ] **P5-002** オフライン可否、ネットワーク、電源、騒音、設営時間を確認する。
- [ ] **P5-003** 来場者画像を扱う場合の掲示、同意、保存期間、削除方針を定義する。
- [ ] **P5-004** 目標 FPS、生成待ち時間、連続稼働時間、復旧時間を定義する。
- [ ] **P5-005** 操作者、保守担当、緊急停止手順を決める。
- [ ] **P5-006** 公開 UI の認証、認可、レート制限、ログ方針を別要件化する。

## P5-B 高解像度・印刷

- [ ] **P5-010** SVG 出力のテキスト保持・アウトライン化を選択可能にする。
- [ ] **P5-011** PDF のページ寸法、塗り足し、フォント処理を実装する。
- [ ] **P5-012** フォントの埋め込み・アウトライン化許諾を出力前に検査する。
- [ ] **P5-013** 大判向けタイル描画でメモリ上限を守る。
- [ ] **P5-014** カラープロファイル、二値化、ドットゲインを校正する。
- [ ] **P5-015** 実寸テスト出力を遠景・近景で評価する。

## P5-C リアルタイム入力

- [ ] **P5-020** カメラと動画ファイルの入力抽象を実装する。
- [ ] **P5-021** フレーム選択、リサイズ、プライバシーマスクを実装する。
- [ ] **P5-022** 密度マップと描画の差分更新を実装する。
- [ ] **P5-023** AI 呼出頻度と費用を上限内に制御する。
- [ ] **P5-024** ネットワーク断では保存済み文章またはローカル素材へ切り替える。
- [ ] **P5-025** フレーム落ち、遅延、メモリ増加を長時間試験する。

## P5-D 出力機器と音響

- [ ] **P5-030** プロジェクター・LED の解像度、色、遅延を抽象化する。
- [ ] **P5-031** 表示領域のキャリブレーションと安全域を実装する。
- [ ] **P5-032** 読み上げ・音響を作品単位で有効化できるようにする。
- [ ] **P5-033** 表示と音響の同期ずれを測定・補正する。
- [ ] **P5-034** 音量上限、停止、無音フォールバックを実装する。

## P5-E 運用

- [ ] **P5-040** 自動起動、全画面復帰、ヘルスチェックを実装する。
- [ ] **P5-041** ログ容量上限と個人情報を含まない監視項目を決める。
- [ ] **P5-042** クラッシュ後に最後の有効作品へ復帰する。
- [ ] **P5-043** 8時間以上の連続稼働試験を実施する。
- [ ] **P5-044** 設営、日次確認、障害対応、撤収の手順書を作る。
- [ ] **P5-045** 展示終了時に来場者データを方針どおり削除する。

## 完了ゲート

- [ ] **P5-G01** 実会場条件で遠景・近景の鑑賞体験を確認する。
- [ ] **P5-G02** 連続稼働、ネットワーク断、機器断の復旧試験を通過する。
- [ ] **P5-G03** 権利、プライバシー、安全、アクセシビリティの展示レビューを通過する。
- [ ] **P5-G04** 操作者が手順書だけで起動・復旧・停止できる。
- [ ] **P5-G05** 展示成果と運用課題を次版ロードマップへ反映する。
