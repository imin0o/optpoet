# Phase 2: 写真説明文と散文詩

**状態**: 未着手  
**目標**: 写真から記述文・散文詩を生成し、意味を保ちながら密度最適化する。  
**依存**: [Phase 1](phase-1.md)  
**次**: [Phase 3](phase-3.md)

## 成果物

- 画像解析・文章生成アダプターと保存応答モード
- 編集可能な意味設計データ、草稿、候補、最適化トレース
- 局所再生成、固定、直接編集、進捗・取消

## P2-A AI アダプター

- [ ] **P2-001** プロバイダー非依存の画像解析インターフェースを実装する。
- [ ] **P2-002** プロバイダー非依存の文章生成インターフェースを実装する。
- [ ] **P2-003** モデル、パラメータ、プロンプト版、応答原文を保存する。
- [ ] **P2-004** 保存応答・モック・実サービスを同じ契約で切り替える。
- [ ] **P2-005** タイムアウト、取消、上限付き再試行を実装する。
- [ ] **P2-006** 認証、制限、提供者障害、構造不正を別のエラーとして扱う。
- [ ] **P2-007** 外部送信前の同意表示と EXIF 除去を実装する。
- [ ] **P2-008** API キーがログ・project JSON・例外へ出ないことをテストする。

## P2-B 写真内容の解析

- [ ] **P2-010** 被写体、空間、光、構図、動作、色調、雰囲気を構造化する。
- [ ] **P2-011** 観察事実と推測・詩的解釈を別フィールドへ保存する。
- [ ] **P2-012** 身元・センシティブ属性を推定しないプロンプトと検査を実装する。
- [ ] **P2-013** 作者が各項目を修正・削除・固定できるようにする。
- [ ] **P2-014** AI 失敗時に意味設計データを手入力して続行できるようにする。
- [ ] **P2-015** 同じ保存応答から意味設計データが一致することをテストする。

## P2-C 草稿と候補生成

- [ ] **P2-020** 記述モードの目的、語調、禁止事項をプロンプト化する。
- [ ] **P2-021** 散文詩モードの文体、抽象度、写真との距離をプロンプト化する。
- [ ] **P2-022** 2,000 / 5,000 セル向けに複数区間の草稿を生成する。
- [ ] **P2-023** 草稿を文・文節・形態素へ分解し、位置を保持する。
- [ ] **P2-024** 語句ごとの言い換え、表記、語順候補を生成する。
- [ ] **P2-025** 候補の文字数、密度、品詞、意味類似度を計算する。
- [ ] **P2-026** 禁止語、重複、未知語、許可文字集合違反を候補から除外する。

## P2-D 制約探索と局所修正

- [ ] **P2-030** 視覚・文章・意味・文体の評価値を同一スケールへ正規化する。
- [ ] **P2-031** 写真優先・均衡・文章優先プリセットを実装する。
- [ ] **P2-032** ビームサーチまたは局所探索で文節候補を配置する。
- [ ] **P2-033** 文字数、禁則、固定語句をハード制約にする。
- [ ] **P2-034** 誤差の大きい区間だけ AI へ再入力する。
- [ ] **P2-035** 改善停止、反復上限、費用上限、取消を終了条件にする。
- [ ] **P2-036** 初期草稿から最終文までの採否をトレースへ保存する。

## P2-E 作者操作と検証

- [ ] **P2-040** 画像解釈、冒頭文、語句、人称、時制、領域を固定できるようにする。
- [ ] **P2-041** 固定範囲を除外した局所再生成を実装する。
- [ ] **P2-042** 直接編集後にセル数・グリフ・視覚誤差を再検証する。
- [ ] **P2-043** 外部 AI の送信予定、進捗、概算呼出量を表示する。
- [ ] **P2-044** 記述と散文詩を同じ画像・設定で比較できるようにする。
- [ ] **P2-045** ネットワークなしに全受入テストを保存応答で実行する。
