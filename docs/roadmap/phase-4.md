# Phase 4: 領域と意味の対応

**状態**: 未着手  
**目標**: 画像領域ごとに視覚優先度と語彙を変え、位置と意味の結びつきを強める。  
**依存**: [Phase 3](phase-3.md) と MVP 振り返り  
**次**: [Phase 5](phase-5.md)

## 成果物

- セグメンテーションと作者修正可能な領域マップ
- 領域別語彙、意味マップ、反転対応
- 局所形状評価、領域再生成、縦書き試作

## P4-A 領域マップ

- [ ] **P4-001** 人物、空、建物、前景、背景の領域スキーマを定義する。
- [ ] **P4-002** セグメンテーションアダプターを交換可能に実装する。
- [ ] **P4-003** 領域ごとの確信度とモデル識別子を保存する。
- [ ] **P4-004** 作者が領域を追加・削除・結合・修正できるようにする。
- [ ] **P4-005** 顔や輪郭を高優先度にするマスクを編集可能にする。
- [ ] **P4-006** セグメンテーションなしの既存プロジェクトを互換読込する。

## P4-B 意味マップ

- [ ] **P4-010** 暗部、明部、輪郭、顔、背景の意味カテゴリを定義する。
- [ ] **P4-011** 領域ごとの推奨語彙・禁止語彙を作者が編集できるようにする。
- [ ] **P4-012** 形式的対応、意味的対応、反転対応を選べるようにする。
- [ ] **P4-013** 語句と使用領域の対応を最適化トレースへ保存する。
- [ ] **P4-014** 領域語彙を固定した局所再生成を実装する。
- [ ] **P4-015** センシティブ属性の推定禁止を領域処理にも適用する。

## P4-C 局所形状

- [ ] **P4-020** 文字の左右・上下半分の密度を辞書へ追加する。
- [ ] **P4-021** 黒画素重心とエッジ方向を辞書へ追加する。
- [ ] **P4-022** 画像セル側にも同じ局所特徴を計算する。
- [ ] **P4-023** 平均密度と局所形状の重みを独立設定する。
- [ ] **P4-024** 顔・輪郭領域だけ局所形状評価を強める。
- [ ] **P4-025** MAE 改善と主要構図認識のトレードオフを評価する。

## P4-D 読み順拡張

- [ ] **P4-030** 領域別読み順を project schema へ追加する。
- [ ] **P4-031** 領域境界で文章を接続・分離する規則を実装する。
- [ ] **P4-032** 縦書きのセル順、禁則、句読点、回転グリフを定義する。
- [ ] **P4-033** 縦書き用密度辞書と描画整合を検証する。
- [ ] **P4-034** 横書きプロジェクトとの互換性を維持する。

## 完了ゲート

- [ ] **P4-G01** 領域推定を作者が修正し、再生成へ反映できる。
- [ ] **P4-G02** 形式・意味・反転の三対応を同一画像で比較できる。
- [ ] **P4-G03** 局所形状評価が主要輪郭を改善する検証記録がある。
- [ ] **P4-G04** 領域・縦書き拡張後も MVP プロジェクトを一致再生できる。
- [ ] **P4-G05** 新しい権利・プライバシーリスクをレビュー済みである。
