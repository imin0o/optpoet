# Phase 3: 光学的韻律と簡易カットアップ

**状態**: 未着手  
**目標**: 文字種・書体・意図的な文法破綻を光学的韻律として操作可能にする。  
**依存**: [Phase 2](phase-2.md)  
**次**: MVP 判定後に [Phase 4](phase-4.md)

`MVP 必須` と記したタスクだけが初回リリース範囲であり、残りは Phase 3 継続項目とする。

## 成果物

- 文字種別の固定フォントと書体別密度辞書
- 文法秩序、簡易カットアップ、密度波形・文字種比率表示
- 同一写真の記述・散文詩・カットアップ比較

## P3-A 書体と文字種リズム

- [ ] **P3-001 MVP 必須** 漢字・ひらがな・カタカナ・記号へ固定フォントを割り当てる。
- [ ] **P3-002 MVP 必須** 書体別の密度辞書を生成・識別する。
- [ ] **P3-003 MVP 必須** ベースライン、字面、仮想ボディ、字間の差を補正する。
- [ ] **P3-004 MVP 必須** 暗部の漢字率、明部のひらがな率を補助制約にする。
- [ ] **P3-005 MVP 必須** 文字種率と密度誤差の競合を評価トレースへ記録する。
- [ ] **P3-006** 明部 Light / 中間 Regular / 暗部 Bold の有効性を実験する。
- [ ] **P3-007** ウェイト変更と文字選択の効果が重複する場合の優先規則を決める。

## P3-B 文法秩序

- [ ] **P3-010 MVP 必須** 文法秩序 1.0〜0.0 のプリセットを実装する。
- [ ] **P3-011 MVP 必須** 助詞削除、文節交換、主語省略、時制変更を個別設定する。
- [ ] **P3-012 MVP 必須** 断片挿入、語句反復、文中切断を個別設定する。
- [ ] **P3-013 MVP 必須** 記述・散文詩で安全上限を超える操作に確認を求める。
- [ ] **P3-014 MVP 必須** 実際の破綻率と設定値の差を計測する。
- [ ] **P3-015** 破綻位置と画像の密度変化位置の対応を可視化する。

## P3-C 簡易カットアップ

- [ ] **P3-020 MVP 必須** AI 生成文と作者入力文を複数素材として登録する。
- [ ] **P3-021 MVP 必須** 素材ごとに出典、権利状態、言語を記録する。
- [ ] **P3-022 MVP 必須** 日本語の文節単位で切断する。
- [ ] **P3-023 MVP 必須** 文節の長さ、平均密度、意味ベクトル、語尾を計測する。
- [ ] **P3-024 MVP 必須** 密度波形への適合とランダム性で再配置する。
- [ ] **P3-025 MVP 必須** シード、反復回数、固定断片を保存する。
- [ ] **P3-026 MVP 必須** 不足・超過セルを規則に従って調整する。
- [ ] **P3-027** 文字・形態素・任意長による切断を実験機能として追加する。
- [ ] **P3-028** 音の類似や語尾による再配置を実験する。

## P3-D 比較と評価

- [ ] **P3-030 MVP 必須** 読み順に沿った密度波形を表示する。
- [ ] **P3-031 MVP 必須** 局所的な漢字・ひらがな・カタカナ率を表示する。
- [ ] **P3-032 MVP 必須** 同一写真から記述、散文詩、簡易カットアップを並べる。
- [ ] **P3-033 MVP 必須** 書体、文字種、視覚密度の各リズム評価を保存する。
- [ ] **P3-034 MVP 必須** カットアップでは自然さを合格条件から外して評価する。
- [ ] **P3-035** 光学詩モードと視覚優先モードを実験機能として比較する。

## MVP 完了ゲート

- [ ] **P3-G01** すべての `MVP 必須` タスクが完了している。
- [ ] **P3-G02** 素材来歴を欠いたカットアップ作品を書き出せない。
- [ ] **P3-G03** 設定した文法秩序と測定した破綻率の差を説明できる。
- [ ] **P3-G04** 3 形式すべてを保存・再読込・一致再生できる。
- [ ] **P3-G05** 同一写真 12 枚の比較展示と人間評価記録がある。
