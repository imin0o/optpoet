# 人間評価票と評価手順

**状態**: P0-033 作成完了  
**目的**: [quality-and-operations.md](../quality-and-operations.md) 8章「人間による評価」を、第三者が再現できる評価票と手順に固定する。  
**関連**: [quality-and-operations.md](../quality-and-operations.md) 8章、[validation-dataset.md](validation-dataset.md)、[requirements.md](../requirements.md)

本書は記述・散文詩の出力に対する主観評価を、同一の観点・尺度・提示条件・集計規則で
実施できるようにする正規手順である。自動受入条件（[quality-and-operations.md](../quality-and-operations.md)
7章 AC-01〜AC-07）を補完し、数値だけでは測れない作品価値を人手で判定する。カットアップは
別扱いとする（5章）。

## 1. 評価対象と評価者

- **対象出力**: 記述（description）と散文詩（prose-poem）。1 作品 = 検証画像 1 枚から
  1 モードで生成した TXT + PNG の組。カットアップは 5章の別票で扱う。
- **評価者**: 作者を含む **3 人以上**。各評価者は独立に評価し、他者のスコアを見ない。
- **記録単位**: (画像 slot, モード, プロンプト/モデル/フォント/設定/シード) の 1 組に対し
  評価者ごと 1 票。集計は 3章の規則で行う。
- 評価者の氏名または識別子・評価日を票へ記録する（来歴保持のため）。

## 2. 提示条件（遠景・近景）

観点により遠景・近景の 2 距離で提示する。距離は環境非依存にするため相対定義とする。

- **遠景**: PNG 全体が一視野に収まり、個々の文字が判読不能になる距離・表示倍率。
  主要構図（被写体の輪郭・明暗配置）の知覚を確認する。
- **近景**: 文字列が無理なく判読できる距離・表示倍率。読みの連続性・文体を確認する。
- 表示媒体は [reference-pc.md](reference-pc.md) の参照環境を基準とし、等倍表示（100%）を
  既定とする。倍率を変えた場合は票へ記録する。
- 提示順は遠景 → 近景を既定とする（構図印象を読みで上書きしないため）。

## 3. 評価観点と 5 段階アンカー

[quality-and-operations.md](../quality-and-operations.md) 8章の 5 観点を用いる。各観点を
1〜5 の 5 段階で評価する。1=全く当てはまらない、3=どちらとも言えない/最低限、
5=明確に当てはまる。判断のぶれを抑えるため各観点にアンカーを定義する。

| # | 観点 | 提示距離 | 1（不足） | 3（最低限） | 5（良好） |
| --- | --- | --- | --- | --- | --- |
| Q1 | 遠景で主要構図を識別できる | 遠景 | 何の像か分からない | 大まかな配置は分かる | 被写体・構図が明確に読み取れる |
| Q2 | 近景で最後まで読み進められる | 近景 | 途中で読めず脱落する | 努力すれば通読できる | 抵抗なく最後まで読める |
| Q3 | 写真との意味的関連がある | 近景 | 内容が写真と無関係 | 部分的に関連する | 主題・細部が写真と対応する |
| Q4 | 文体と意図した文法秩序が一致する | 近景 | 指定文体・語順と乖離 | 概ね一致し逸脱は軽微 | 意図した文体・文法秩序に合致 |
| Q5 | 文字種・書体の変化が光学的韻律として知覚できる | 遠景+近景 | 変化を知覚できない | 変化はあるが韻律に乏しい | 濃淡・書体変化がリズムとして働く |

- Q4 の「意図した文体・文法秩序」は、その作品の生成時に指定した文体・語順（散文詩／記述）を
  基準とする。基準は票へ併記する。
- 各観点は独立に採点し、総合印象で他観点を引きずらない。

## 4. 集計と合格判定

- 観点ごとに全評価者スコアの **中央値** を取る（平均でなく中央値。外れ値の影響を抑えるため）。
- **MVP 暫定合格**: Q1〜Q5 の各中央値が **3 以上**、かつ重大な権利・プライバシー問題が **0 件**。
- 中央値が 3 未満の観点が 1 つでもあれば不合格とし、該当観点と代表コメントを記録して
  次工程の改善対象にする。
- 権利・プライバシー問題（写り込んだ個人情報、権利不明素材の混入等）は観点スコアと独立に
  チェックし、1 件でもあれば重大とみなして合格させない。
- スコアは作品の可否判定に用い、単一数値で作品価値を断定しない（自由記述コメントを併記する）。

## 5. カットアップの別扱い

カットアップ（cut-up）は自然さ・可読性を合格条件にしない。

- 評価軸: **設定した破綻率との一致**（意図した崩れ量に対する実際の崩れの近さ）と
  **作者の意図との整合**を、それぞれ 1〜5 で採点する。
- 合格条件は作者判断とし、Q1〜Q5 の中央値基準は適用しない。破綻率の目標値と観測値を票へ記録する。

## 6. 評価票テンプレート

1 作品 1 票。評価者ごとに 1 枚。以下を Markdown 表または同等の記録に残す。

```md
## 人間評価票

- 作品ID: <slot>-<mode>-<連番>       例: portrait-1-description-001
- 画像 slot: <portrait-1 等>          （[validation-dataset.md](validation-dataset.md) 3章）
- モード: description / prose-poem / cut-up
- 生成条件: プロンプト / モデル / フォント / 設定 / シード
- 評価者: <識別子>
- 評価日: YYYY-MM-DD
- 表示倍率: 100%（変更時は実値）

### スコア（1〜5）

| 観点 | スコア | コメント |
| --- | --- | --- |
| Q1 遠景で主要構図を識別できる |  |  |
| Q2 近景で最後まで読み進められる |  |  |
| Q3 写真との意味的関連がある |  |  |
| Q4 文体と意図した文法秩序が一致する |  |  |
| Q5 文字種・書体の変化が光学的韻律として知覚できる |  |  |

### 権利・プライバシー

- 重大な問題: 有 / 無（有の場合は内容）

### 自由記述

- <遠景・近景で気づいた点、改善要望など>
```

カットアップ用票は「スコア」表を次に差し替える。

```md
### カットアップ評価（1〜5）

| 軸 | 目標 | 観測 | スコア | コメント |
| --- | --- | --- | --- | --- |
| 破綻率の一致 | <目標破綻率> | <観測破綻率> |  |  |
| 作者の意図との整合 | - | - |  |  |
```
