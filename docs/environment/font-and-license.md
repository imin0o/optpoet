# 基準日本語フォントとライセンス

**状態**: 決定（2026-07-25）
**目的**: 密度辞書と最終描画で共有する基準日本語フォントと、その配布・埋め込み・再配布に関わるライセンスを固定し、描画一貫性（NFR-02）・グリフ網羅（AC-02）・出力時の権利検査（P5-012）の基準にする。
**対象タスク**: [P0-012](../roadmap/phase-0.md)
**関連**: [requirements.md](../requirements.md)（FR-08 / FR-11 / FR-12）、[quality-and-operations.md](../quality-and-operations.md)（NFR-02 / AC-02）、[open-issues.md](../decisions/open-issues.md)（OI-001）、[reference-pc.md](reference-pc.md)、[python-and-libraries.md](python-and-libraries.md)

本書は「基準日本語フォントをどれにし、どのライセンス根拠で埋め込み・アウトライン化・再配布するか」を確定する正規決定記録である。密度辞書キー（[P1-023](../roadmap/phase-1.md)）とレンダラ（[P0-013](../roadmap/phase-0.md)）は本書の決定を前提にする。実際の版固定とハッシュ記録は配布物取り込み時（[P1-020](../roadmap/phase-1.md)）に行う。

## 決定要件（何を満たすフォントか）

| 要件 | 根拠 | 判断への影響 |
| --- | --- | --- |
| 版・ファイルを固定でき、ハッシュで同一性を保証できる | NFR-02、[P1-020](../roadmap/phase-1.md) | OS 同梱フォント（Yu Gothic 等、版が環境で変動）は基準にしない。プロジェクトへ**固定版ファイルを同梱**する方式に限定。 |
| 漢字・ひらがな・カタカナ・記号を欠落グリフなく網羅 | AC-02（暗黙代替 0 件）、FR-08 | JIS X 0208/0213・常用/人名漢字を広く覆う CJK フォントを選ぶ。 |
| 埋め込み・アウトライン化・再配布が許諾で明快 | quality 45-47、[P5-012](../roadmap/phase-5.md) | 制約の少ない自由ライセンス（SIL OFL）を最優先。 |
| 文字種別に固定フォントを割り当てられる | FR-11、[P3-001](../roadmap/phase-3.md) | 同一ファミリでゴシック／明朝を揃えられると混在設計が単純。 |
| 密度差を出せる複数ウェイト | 概念（書体・密度）、FR-11 | 多ウェイト保有を加点。 |

## 決定

- **基準フォント（ゴシック・既定）**: **源ノ角ゴシック / Source Han Sans（= Noto Sans CJK JP）**
- **基準フォント（明朝・選択肢）**: **源ノ明朝 / Source Han Serif（= Noto Serif CJK JP）**
- **ライセンス**: **SIL Open Font License 1.1（OFL-1.1）**
- **配布形態**: 上記の**特定版 OTF/TTF を JP サブセットでプロジェクトへ同梱**し、版番号と SHA-256 を [P1-020](../roadmap/phase-1.md) で記録する。採用版は取り込み時の最新安定版（Source Han Sans 2.004 系相当）を候補とし、確定版を本書「更新履歴」へ追記する。
- **ウェイト**: 7 ウェイト（ExtraLight〜Heavy）を保有。密度辞書は使用ウェイトをキーに含める（[P1-023](../roadmap/phase-1.md)）。

## 根拠

- **OFL-1.1 が権利要件に最も明快**: 商用可・**埋め込み可・アウトライン化可・再配布可・改変可**で、出力（PNG/PDF）へのグリフ埋め込みとアウトライン化を無条件に許容する。これにより quality 45-47 と [P5-012](../roadmap/phase-5.md) の出力前検査が「OFL 準拠」の一点確認で済む。
- **グリフ網羅が広い**: 源ノ角ゴシックは JIS X 0208/0213・常用/人名漢字を広く覆い、MVP 許可文字集合で欠落グリフを出しにくい（AC-02 の 0 件目標）。網羅の実測は描画整合スパイク [P0-014](../roadmap/phase-0.md) で確認する。
- **同一設計のゴシック／明朝が揃う**: 源ノ角ゴシックと源ノ明朝は字面設計が対応し、FR-11 の「文字種ごとに固定フォント」を同系統で構成できる。将来の書体混在も設計が連続する。
- **多ウェイトで密度差を作れる**: 7 ウェイトは同一グリフで黒画素率を段階的に変えられ、密度辞書の表現幅を確保する（概念の「書体・密度」）。
- **版固定が容易**: 配布ファイルが版ごとに公開されており、特定版を同梱してハッシュ固定できる。OS 同梱フォントの版変動リスク（NFR-02 違反）を回避する。

## 却下・保留した選択肢

| 案 | 却下/保留理由 |
| --- | --- |
| IPAexゴシック / IPAex明朝（IPA Font License 1.0） | ライセンス自体は埋め込み・アウトライン化可だが、**派生・再配布時の名称制約とライセンス継承**があり、OFL より運用注意点が多い。ウェイトも実質単一。**フォールバック候補**として保持（源ノ系の取得・版固定に支障が出た場合に切替）。 |
| Yu Gothic / Meiryo 等 OS 同梱フォント | 版が環境・OS 更新で変動し NFR-02（同一ファイル・版）を満たせない。埋め込み・再配布の許諾も自由フォントより不明瞭。基準にしない。 |
| 商用フォント（モリサワ等） | ライセンス費用と再配布制約が MVP の権利要件（quality 45-47）と検証再現性（第三者再利用、[P0-G03](../roadmap/phase-0.md)）に合わない。対象外。 |

## MVP での運用

- **文字種割り当て（FR-11 / [P3-001](../roadmap/phase-3.md)）**: 既定は漢字・ひらがな・カタカナ・記号すべてを **源ノ角ゴシック単一ファミリ**に割り当てる。装飾意図で明朝を使う場合のみ源ノ明朝を選択肢に加える。文字単位の任意フォント指定は MVP 対象外（FR-11）。
- **同一性保証**: 密度測定時と最終描画時で、同梱した**同一ファイル・同一版・同一ハッシュ**を使う（NFR-02）。ハッシュはフォントプロファイルに保存する（[P1-020](../roadmap/phase-1.md) / [P1-023](../roadmap/phase-1.md)）。
- **欠落グリフ**: 暗黙代替を行わず、不足文字と位置を作者へ示す（FR-08 / AC-02）。基準フォントで賄えない文字が出た場合は本書と OI へ差し戻す。
- **出力前検査**: PNG/PDF 出力前に「OFL-1.1 準拠・アウトライン化許諾あり」を検査項目として確認する（[P5-012](../roadmap/phase-5.md)）。

## 未確定・次工程へ委譲

- **採用版・ハッシュの確定**: 具体的な版番号と SHA-256 は取り込み時に固定し、[P1-020](../roadmap/phase-1.md) と本書「更新履歴」に記録する。基準フォントファイルの最終選定・同梱は実装後に確定してよく、それまでは OS 同梱の Noto Sans JP（源ノ角ゴシック相当）を暫定使用する（[pixel-identity-spike.md](pixel-identity-spike.md) の実測もこれを用いた）。
- **グリフ網羅の実測**: MVP 許可文字集合での欠落 0 件確認は [P0-014](../roadmap/phase-0.md)（同一画素スパイク）で行う。
- **描画エンジン整合**: フォントのヒンティング・アンチエイリアスが密度辞書と最終描画で一致することは [P0-013](../roadmap/phase-0.md) / [P0-014](../roadmap/phase-0.md) で確認する。
