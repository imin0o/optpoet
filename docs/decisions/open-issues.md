# 未決事項一覧

本書は optpoet の未決事項（論点）と決定を管理する正規情報源である。要件・設計・ロードマップに影響する
判断は本書へ登録し、決定後もエントリを残して来歴を保持する。関連文書は
[requirements.md](../requirements.md)、[architecture.md](../architecture.md)、
[ROADMAP](../roadmap/phase-0.md) を参照する。

## 記入規則

- 1 論点につき 1 エントリを作り、ID は `OI-NNN`（連番、再利用しない）を付ける。
- 状態は `未決 / 検討中 / 決定 / 見送り` のいずれかとする。
- 未決・検討中のエントリには必ず担当と期限を設定する（完了ゲート P0-G01）。
- 決定後も行は削除せず、状態を `決定` にして決定内容・根拠・決定日を記録する。
- MVP 影響は `必須 / 望ましい / 対象外` で分類し、MVP 境界の判断根拠にする。

## 項目定義

| 項目 | 内容 |
| --- | --- |
| ID | `OI-NNN` の一意な識別子 |
| 論点 | 決めるべき問いを一文で記述する |
| 選択肢 | 検討中の案を列挙し、各案のメリット・リスクを短く添える |
| 決定 | 採用した結論。未決時は空欄 |
| 根拠 | 決定に至った理由と却下理由 |
| MVP 影響 | `必須 / 望ましい / 対象外` |
| 担当 | 判断責任者 |
| 期限 | 決定目標日（`YYYY-MM-DD`） |
| 状態 | `未決 / 検討中 / 決定 / 見送り` |
| 決定日 | 状態を `決定` にした日（`YYYY-MM-DD`） |

## エントリテンプレート

各エントリは以下の見出し形式で追記する。

```markdown
### OI-NNN 論点の要約

- **論点**: 決めるべき問いを一文で。
- **選択肢**:
  - 案A: 概要 — メリット / リスク
  - 案B: 概要 — メリット / リスク
- **決定**: 採用結論（未決なら「未決」）。
- **根拠**: 採用理由と却下理由。
- **MVP 影響**: 必須 / 望ましい / 対象外
- **担当**:
- **期限**: YYYY-MM-DD
- **状態**: 未決 / 検討中 / 決定 / 見送り
- **決定日**: YYYY-MM-DD（未決なら空欄）
```
