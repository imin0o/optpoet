# 要件定義

本書は optpoet の機能、MVP 境界、受入条件の正規情報源である。品質・運用・権利・検証方法は
[quality-and-operations.md](quality-and-operations.md)、実現方式は
[architecture.md](architecture.md) を参照する。要件変更は本書と関連文書を同時に更新する。

## 1. 対象者と利用形態

- 主利用者は、自身または適法に利用できる写真と文章から作品を制作する作者である。
- MVP は作者一人がローカル環境で対話的に使う制作ツールとし、一般公開サービスや共同編集は対象外とする。
- 作者は生成結果を採用する前に、画像解釈、文章、権利、最終表現を確認・修正できる。

## 2. 用語

| 用語 | 定義 |
|---|---|
| セル | 出力グリッド上で一つの表示文字を置く領域 |
| 密度 | 使用フォントと描画条件でセル内が黒く塗られる面積比 |
| 密度マップ | 入力画像をセル単位へ縮小した 0.00（白）〜1.00（黒）の二次元配列 |
| 密度列 | 密度マップを読み順に並べた一次元配列 |
| 文字密度辞書 | 文字・フォント・ウェイト・描画条件ごとの密度と属性 |
| 光学的韻律 | 写真の光学構造が文字種、書体、語彙、文法へ与える視覚的リズム |
| プロジェクト | 入力、設定、中間生成物、最終結果、来歴をまとめた保存単位 |

## 3. 基本ワークフロー

1. 作者が画像を読み込み、トリミングと階調を調整する。
2. グリッド、フォント、文章モード、視覚と文章の重みを指定する。
3. システムが密度マップと画像解釈を提示し、作者が必要なら修正する。
4. 草稿生成、文字数調整、密度最適化、レンダリングを実行する。
5. 作者が比較表示で評価し、領域・語句・設定を固定して再生成または直接編集する。
6. 作品と再現に必要なプロジェクトデータを保存・書き出す。

## 4. 機能要件

### FR-01 画像入力と前処理

- JPEG / PNG / TIFF / WebP を読み込み、EXIF Orientation、ICC プロファイル、透過を正規化する。
- トリミング、回転、明るさ、コントラスト、白黒反転、ガンマを非破壊設定として保持する。
- MVP 上限は 50 メガピクセルか 100 MB の小さい方とし、超過時は理由と縮小案を表示する。
- 外部 AI へ送る画像からは、解析に不要な EXIF を除去する。

### FR-02 グリッド変換

- 横・縦セル数、セル縦横比、出力サイズ、フォントサイズ、行間、字間を設定できる。
- フォントの実測字面と行送りを縮小・描画の双方へ反映する。
- MVP の作品サイズは 2,000〜5,000 セルとし、5,001〜8,000 セルは試験扱いとする。

### FR-03 密度マップ生成

- 平均明度を基本とし、ガンマ、局所コントラスト、エッジ重みを選択できる。
- 元画像、密度マップ、エッジ補助結果を比較でき、設定を再編集できる。

### FR-04 文字密度辞書

- ひらがな、カタカナ、常用漢字、句読点、許可記号、空白を実際の描画エンジンで測定する。
- キーは文字、フォントファイルのハッシュ、ウェイト、サイズ、描画設定の組み合わせとする。
- MVP は黒画素率を必須とし、重心、方向別密度、形状は拡張属性とする。
- 欠落グリフや代替フォントへの暗黙の置換を禁止し、対象文字と位置を作者へ示す。

### FR-05 写真内容の解析

- マルチモーダル AI から被写体、空間、光、構図、動作、色調、雰囲気、象徴候補を抽出する。
- 観察できる事実と推測・詩的解釈を分離して保存し、作者が編集・固定できる。
- 人物の身元やセンシティブ属性を画像だけから推定しない。

### FR-06 文章モード

- 記述、散文詩、光学詩、カットアップ、視覚優先を定義する。
- MVP は記述、散文詩、簡易カットアップを実装する。残りは UI 上で選択不可とする。

### FR-07 読み順

- MVP は横書き（左から右、上から下）のみとする。
- 縦書き、蛇行、領域別の読み順を将来拡張としてデータ上で識別できる。

### FR-08 密度制約付き文章生成

`visual_similarity`、`language_quality`、`image_relevance`、`style_consistency` の重みを保存し、
写真優先・均衡・文章優先のプリセットと個別調整を提供する。

### FR-09 文章生成方式

1. AI が意味的な草稿と複数の素材を生成する。
2. 草稿を文・文節・形態素へ分解し、言い換え候補を作る。
3. 候補密度を測定し、密度列に適合する組み合わせを探索する。
4. 誤差の大きい区間だけ修正し、規定回数または改善停止まで反復する。
5. 初期草稿、候補、採否、評価値を追跡可能にする。

### FR-10 文字数とセル数

- 正規化形式は NFC とし、MVP の許可文字集合外にある結合文字・絵文字は入力時に示す。
- 表示文字、句読点、全角・半角空白は各 1 セル、改行はセルに数えない。
- 最終表示文字数はセル数と一致させ、行頭禁則、文末位置、最終行の緩和規則を保存する。

### FR-11 文字種と書体のリズム

- 暗部の漢字率、明部のひらがな率、中間部のカタカナ率を補助制約として調整できる。
- MVP の複合フォントは「文字種ごとに一つの固定フォントを割り当てる」方式に限定する。
- 文字単位の任意フォント指定や自動的な多段ウェイト変更は MVP 対象外とする。

### FR-12 レンダリングと出力

- フォント、文字色、背景色、字間、行間、アンチエイリアス、二値化、反転を反映する。
- MVP 必須出力は PNG、UTF-8 TXT、プロジェクト JSON とする。
- SVG、PDF、アウトライン化、高解像度印刷は MVP 後とする。
- TXT とレンダリング結果のセル列が一致することを検証してから出力する。

### FR-13 比較表示

元画像、前処理後画像、密度マップ、草稿、最終文章、完成画像、差分、誤差ヒートマップ、
密度波形、文字種比率を同じプロジェクト内で比較できる。

### FR-14 再生成と編集

シード、画像解釈、文体、語句、領域、時制、密度、生成段階を固定し、影響範囲だけ再生成できる。
文章の直接編集後は文字数・欠落グリフ・視覚誤差を再検証する。

### FR-15 カットアップ

- AI 生成文、作者入力文、適法に利用できる既存テキストを素材にできる。
- 素材ごとに出典、権利状態、言語を記録する。
- MVP は日本語の文節単位の切断・再配置・反復に限定する。

### FR-16 可読性とカオス

文法秩序 1.0〜0.0 に加え、助詞削除、文節交換、主語省略、時制変更、断片挿入、語句反復、
文中切断を個別設定する。記述・散文詩では安全な上限を設け、明示操作なしに文章を破壊しない。

### FR-17 プロジェクト保存

入力ファイルのハッシュ、前処理、密度辞書識別子、AI 入出力、モデル識別子、設定、シード、
編集履歴、評価、出力をスキーマ版付きで保存し、再読込と結果の再生を可能にする。

### FR-18 進捗・中断・失敗

各工程の進捗、外部 AI 利用の有無、概算処理量を表示する。作者は生成を中断でき、
完了済み中間生成物を失わない。再試行可能な失敗と設定修正が必要な失敗を区別する。

## 5. 作者が操作する主要パラメータ

| 分類 | パラメータ |
|---|---|
| 画像 | トリミング、反転、コントラスト、ガンマ、エッジ重み |
| 組版 | グリッド、出力サイズ、フォント、行間、字間 |
| 文章 | モード、文体、抽象度、人称、時制、漢字率、反復率 |
| 最適化 | 視覚・文章・意味・文体の重み、密度許容差、反復上限、シード |
| 破綻 | 文法秩序と FR-16 の個別率 |

## 6. MVP の範囲

- 1 枚の写真、日本語、横書き、2,000〜5,000 セル、単一作者のローカル利用。
- 記述・散文詩・簡易カットアップ、文字種別の固定フォント、黒文字・白背景。
- 比較表示、局所再生成、直接編集、PNG / TXT / プロジェクト JSON 保存。
- 合格条件と検証方法は [quality-and-operations.md](quality-and-operations.md) に従う。

## 7. MVP では実装しない

動画・カメラ・リアルタイム入力、縦書き、領域別物語、任意のフォント混在、色付き文字、
完全な文字単位 AI 生成、音声、展示機器制御、スマートフォン、共同編集、公開 SaaS、
独自大規模モデル学習、複雑な音韻・モーラ制御、SVG / PDF / 印刷ワークフロー。
