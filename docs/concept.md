# コンセプト

## 1. 作品の定義

optpoet は、モノクロ写真の明暗・輪郭・光の分布を、文字の視覚密度・書体・文字種・語彙・文法構造へ変換する生成詩システムである。

本作品における文章は、写真を説明するキャプションではない。また、文字を用いて写真を再現するだけのアスキーアートでもない。

写真の光学構造が、文字・書体・語彙・文法・改行・反復を決定することで、**写真そのものが文章の形式を生成する**。詩における韻や音数に相当するものを、光と影・線と面・明暗の勾配から取り出す。

その結果、文章は意味を伝えるだけでなく、写真の光学的時間を読むための譜面となる。

### 1.1 作者と鑑賞者

主たる作者は、写真・文章・書体を選び、生成過程へ介入しながら作品を制作する人である。
AI は完成品の決定者ではなく、画像解釈と文章素材の供給者として位置づける。採用、修正、権利確認、
展示判断は作者が担う。

鑑賞体験は二つの距離を往復する。遠景では写真の構図と明暗を認識し、近景では文章を読み、
その間で文字種・書体・文法の変化を光学的韻律として知覚する。単に画像類似度を最大化することは
目的ではなく、この往復が成立する余地を残す。

## 2. 中心命題

```
写真の明暗
    ↓
文字の濃度
    ↓
文字種と書体
    ↓
文節と語彙のリズム
    ↓
文章の意味と文法
```

従来の詩において、韻律は主に聴覚的・時間的な構造として扱われてきた。本作品では、写真の光と影を文章の構成原理として使用し、文章へ視覚的・空間的な韻律を導入する。

したがって、写真は文章の内容を説明する対象であるだけでなく、**文章を拘束する形式装置**でもある。

## 3. 三つの同時成立と緊張関係

本作品は次の三つを同時に成立させる。

1. **見ると写真** — 視覚的再現性
2. **読むと文章** — 日本語としての可読性
3. **文字の密度変化そのものが韻律** — 光学的韻律

画像再現性だけを重視すると文章が崩れ、文章だけを重視すると画像が崩れる。この二者間の緊張関係を作品の本質として扱う。

## 4. 光学的韻律

写真の光学的構造によって文章へ与えられる視覚的なリズムを、本作品では **光学的韻律** と呼ぶ。

光学的韻律は単一の文字密度ではなく、複数の階層から構成される。

### 4.1 文字レベル
黒画素率 / 画数 / 字形の複雑さ / 重心 / 縦線と横線の比率 / 書体 / 文字種

### 4.2 語レベル
漢字語と和語の切り替え / 漢字表記とひらがな表記の選択 / 語の長さ / 熟語の連続 / 同音語 / 異表記 / 音の反復

例（意味が近くても視覚密度とリズムが異なる）:
```
光が消える
ひかりがきえる
光線が途絶する
明滅が終わる
```

### 4.3 文節レベル
文節長 / 助詞の数 / 修飾語の長さ / 漢字密度 / 句読点までの距離 / 反復される構文

### 4.4 行レベル
一行あたりの文字数 / 行内の明暗変化 / 行頭と行末の密度 / 改行位置 / 文の終端と行の終端の一致またはずれ

### 4.5 画面レベル
写真全体の明暗構造 / 大きな黒い塊 / 光源 / 輪郭 / 遠近 / 被写体と背景 / ネガティブスペース

## 5. 書体によるリズム

アンチック体の構造を参考にし、文字種ごとに書体を切り替える。

- 漢字: ゴシック体（面としての重さ、影に近い）
- ひらがな: 明朝体（線の抑揚、光に近い）
- カタカナ: 設定可能
- 句読点・記号: 独立して設定可能

書体の切り替えは装飾ではなく、光学的韻律を構成する主要なパラメータとする。文章内の漢字とひらがなの切り替わりが、意味や音だけでなく視覚的な強弱として現れる。

ただし明暗と文字種を完全に固定対応させない。実際の文字密度を優先しながら、書体と文字種を韻律上の補助要素として使用する。

## 6. 文法的自然さの位置づけ

文章の自然さは、必ずしも最優先の評価軸としない。光学的韻律への適合を優先することで、次のような現象を積極的に許容する。

文節の断裂 / 主語と述語の不一致 / 時制の急激な変化 / 視点の移動 / 助詞の省略 / 同語反復 / 意味の飛躍 / 語彙領域の衝突 / 文の途中への別文の侵入 / 複数の文章断片の混在

これらを単なる生成失敗とは見なさず、写真の明暗構造によって生じる **文法的カオス** として扱う。文章の破綻は最適化の失敗ではなく、調整可能な表現パラメータとして定義する。

## 7. 光学と意味の対応方法

### 7.1 形式的対応
明暗と文字密度だけを対応させる。意味は明暗と直接対応しなくてもよい。
```
暗い領域 → 密度の高い文字
明るい領域 → 密度の低い文字
```

### 7.2 意味的対応
明暗に意味的な性質を対応させる。
```
暗部 → 重さ、閉塞、記憶、物質、停止
明部 → 呼吸、消失、空白、光、移動
```

### 7.3 反転対応
明暗と意味を意図的に反転させ、視覚と意味の間に緊張や矛盾を作る。
```
暗部 → 軽い語、明るい意味
明部 → 重い語、暗い意味
```

## 8. 作品としての対立軸

これらの軸そのものを、作品生成画面のパラメータとして提示する。

| 軸 | 一方 | 他方 |
|----|------|------|
| 視覚 | 写真の再現 | 文字の可読性 |
| 文法 | 自然な文章 | 文法的カオス |
| 意味 | 写真の説明 | 写真からの逸脱 |
| 書体 | 統一 | 文字種による分裂 |
| 韻律 | 音韻的 | 光学的 |
| 構成 | 連続 | カットアップ |
| 生成 | AIの自由 | 写真による拘束 |
| 解釈 | 単一 | 複数 |
| 明暗 | 意味と一致 | 意味と反転 |

## 9. 初期作品で検証する三つの方向性

同一写真からこの三形式を生成し、比較展示する。

**A. 可読性重視** — 写真説明または散文詩。文法は自然。書体と文字密度によって明暗を表現。遠景と近景の二重の読みを重視。

**B. 光学詩** — 写真の密度波形を優先。漢字とひらがなの切り替えを強調。自然な文章を部分的に崩す。

**C. カットアップ詩** — 複数の文章素材を切断。写真の明暗に従って再配置。文法の破綻を許容。意味の衝突や偶然性を作品化。
